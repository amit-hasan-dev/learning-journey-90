# Learning Journey 90

A mobile-first Progressive Web App for a 90-day Python, Computer Science, Mathematics and Applied AI learning plan.

## Features
- 90-day roadmap and daily lesson pages
- Start-date gate: the plan stays Not Started until you press Start
- Completion tracker and progress summary
- Notes saved locally on the device
- Project checklist, math checklist, English practice tickbox
- Resource library and GitHub repository field
- Ask GPT links with the selected lesson context prefilled
- Export/import JSON backup
- PWA manifest, service worker and offline app shell

## Important
This is a static PWA. Notes and progress are stored in the browser on this device (localStorage); they do not automatically sync across devices. Ask GPT opens ChatGPT with a prepared prompt. It does not attach the complete history of prior ChatGPT conversations. The app's built-in lesson briefs are a starter framework; lesson-by-lesson teaching content can be expanded as the curriculum is finalized.

## Publish free with GitHub Pages
1. Create a GitHub repository, for example `learning-journey-90`.
2. Upload **all files inside this folder** to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site. The URL will look like `https://YOUR-USERNAME.github.io/learning-journey-90/`.

## Install on Android
1. Open the published HTTPS URL in Chrome.
2. Open Chrome's `⋮` menu.
3. Tap **Install app** or **Add to Home screen**.
4. Confirm. The Learning Journey icon will appear on your phone.

Use the app's Export backup button periodically before clearing browser data or changing devices.
